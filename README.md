# Система учёта пациентов (MVC + Tkinter)

Десктопное приложение для ведения базы пациентов с вычислением индекса массы тела (ИМТ), подсветкой опасных показателей и построением сводной статистики.

Проект реализован по архитектурному паттерну **MVC (Model–View–Controller)** с сохранением данных в JSON-файл.

## Функционал

- **Таблица пациентов**: ФИО, возраст, пол, рост, вес, ИМТ.
- **Добавление, редактирование и удаление** пациентов через вертикальную форму.
- **3 варианта пола**: `мужской`, `женский`, `неопределенный`.
- **Валидация ввода**:
  - раздельные поля `Фамилия`, `Имя`, `Отчество` (отчество — необязательное);
  - проверка Ф, И, О регулярным выражением (первая буква заглавная, только буквы и дефис для двойных имён/фамилий);
  - проверка корректности возраста, роста и веса.
- **Цветовая подсветка ИМТ в таблице**:
  - красный — опасный ИМТ (`< 16.0` или `≥ 30.0`);
  - жёлтый — отклонение от нормы (`16.0–18.49` или `25.0–29.99`);
  - без подсветки — норма (`18.5–24.99`).
- **Сводная статистика (4 графика)**:
  1. Распределение пациентов по полу;
  2. Распределение пациентов по возрасту;
  3. Распределение ИМТ с учётом пола;
  4. Зависимость ИМТ от возраста.
- **Автосохранение** данных в файл `patients.json` и автоматическая загрузка при старте программы.

## Структура проекта

```text
├── model.py          # Модель: класс Patient, расчёт ИМТ, валидация, работа с JSON
├── view.py           # Представление: интерфейс Tkinter и графики Matplotlib
├── controller.py     # Контроллер: связывает модель и представление (точка входа)
├── requirements.txt  # Список внешних библиотек
└── README.md         # Документация проекта
```

## Установка и запуск

### Требования

- Python 3.8 или выше
- Установленный `tkinter` (на Windows/macOS идёт вместе с Python; на Ubuntu/Debian при необходимости: `sudo apt install python3-tk`)

### Пошаговая инструкция

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <URL_вашего_репозитория>
cd <папка_проекта>
```

2. Создайте и активируйте виртуальное окружение (рекомендуется):

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```cmd
python -m venv venv
venv\Scripts\activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите приложение:

```bash
python3 controller.py
```

*(на Windows используйте `python controller.py`)*
